# מתכונים

אתר מתכונים אישי בעברית, מימין לשמאל. כל מתכון הוא קובץ Markdown אחד, והאתר הסטטי נבנה לתיקיית `dist/` ומתפרסם ב־GitHub Pages תחת [`/matkonim/`](https://beny-karachun.github.io/matkonim/).

## הוספת מתכון

יוצרים קובץ חדש ב־`content/recipes/`. שם הקובץ, בלי הסיומת, הוא הכתובת: `content/recipes/shakshuka.md` יופיע ב־`/recipes/shakshuka/`. השם חייב להיות באותיות אנגליות קטנות, ספרות ומקפים.

```markdown
---
title: שם המתכון
description: משפט קצר לכרטיס בעמוד הבית
servings: 4
time: 30 דקות
tags:
  - סלט
  - תוספת
---

## מרכיבים

- מרכיב אחד
- מרכיב שני

## רוטב

- מרכיב של הרוטב

## הכנה

1. הצעד הראשון.
2. הצעד השני.

## טיפ

משפט קצר. אפשר גם בלוק ציטוט:

> הערה שנראית כטיפ.
```

- `title`, `description`, `servings`, `time` ו־`tags` חובה. `description` ו־`time` מופיעים בכרטיס, יחד עם התגיות.
- כל קטע (`##`) עם שורות `-` מוצג כרשימת מצרכים עם תיבות סימון. סימון נשמר בדפדפן.
- שורות ממוספרות (`1.` `2.`) מוצגות כשלבי הכנה.
- קטע בשם `טיפ`, או ציטוט (`>`), מוצג כהערת טיפ.
- בעמוד הבית יש חיפוש לפי שם, תיאור או תגית, ואפשר גם ללחוץ על תגית כדי לסנן.

אחר כך מריצים `npm run build`.

## בנייה מקומית

צריך Node.js 20 ומעלה. אין תלויות להתקנה.

```bash
npm test
npm run preview
```

`npm test` בונה את האתר ובודק שהעמודים, המתכון והנתיבים היחסיים תקינים. `npm run preview` מגיש את האתר ב־`http://127.0.0.1:4173/matkonim/`, באותו נתיב בסיס כמו ב־GitHub Pages.
